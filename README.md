## ✨ Features

- **Zero dependencies** — no npm, no bundler, no CDN libraries
- **Custom cursor** — glowing dot + lagging ring that reacts to hover
- **Canvas animations** — hero particle field, project animated backgrounds, contact deep-space scene
- **Scroll-triggered reveals** — timeline, skill bars, and sections animate on scroll
- **Responsive** — works on mobile and desktop

---

## 🛠️ Tech Stack

| Layer | What's used |
|---|---|
| Markup | HTML5 |
| Styling | CSS3 (custom properties, grid, flexbox, keyframes) |
| Logic | Vanilla JavaScript (ES6+) |
| Animations | Canvas 2D API, CSS transitions |
| Fonts | Space Grotesk, Orbitron, JetBrains Mono (Google Fonts) |

## 🚀 Getting Started

No installation needed. Just open the file:

```bash
# Open directly in browser
open index.html

# Or serve locally
npx serve .
# or
python -m http.server 8000
```
